# EYnergyX – Agentic AI Predictive Maintenance Prototype

An end-to-end **Agentic AI system** for autonomous predictive maintenance and proactive service scheduling in the automotive domain.

## 🔍 Overview
This prototype simulates a real-world automotive use case where multiple AI agents collaboratively:
- Predict vehicle component failures
- Assess risk and health scores
- Autonomously schedule service
- Capture feedback and update manufacturing RCA
- Monitor agent behavior using UEBA

## 🧠 Key Features
- Failure prediction from vehicle sensor inputs  
- Multi-agent workflow (Diagnosis, Scheduling, Customer, Feedback, Manufacturing, UEBA)  
- Interactive dashboard with risk distribution and logs  
- Deployed web-based prototype

## 🛠 Tech Stack
- Python, Flask  
- HTML, CSS
